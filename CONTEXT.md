# Pleros Learning Context

This context defines the language used for the SOGP learning journey and its
relationship to reusable PPC lesson content.

## Language

**SOGP level**:
A progression gate containing exactly six required SOGP tracks. Its number
describes the learner journey, not the source lesson's PPC level.
_Avoid_: Week, PPC level

**PPC source level**:
The original level and lesson coordinate of reusable teaching content.
_Avoid_: SOGP level

**Track**:
One required SOGP teaching together with its assessment.
_Avoid_: Extra, optional teaching

**Assessment completion**:
The learning signal that unlocks progression: the required quiz is passed and
the required written response is submitted.
_Avoid_: Audio completion, lesson playback

**Review**:
The required Sunday cohort session, completed live or through its recording.
_Avoid_: Track, optional live class

**Formation requirement**:
Prayer Watch or review participation used for certification but not for level
unlocking.
_Avoid_: Assessment, track completion

**Pre-SOGP**:
The 30-day preparation journey immediately before a learner's SOGP cohort.
_Avoid_: SOGP Level 0
