9 October 2026. Claude Opus 5.5 used the connected Mobbin MCP, ran four screen searches and inspected returned low-resolution image previews. These are individual screens, not verified end-to-end flows. The five selected references are:

They support the same direction rather than adding another visual system.

## Chosen direction

White product shell, faint existing sky accents, hairline panels/tables, Suisse Int'l typography, compact tabular counts, brand-blue actions and readable restrained status accents. Desktop uses a light rail; mobile retains clear navigation to every destination. Keep useful existing SOGP week rhythm and discipleship led/joined separation. Replace the Overview launcher as the primary home; organize Reports around three explicit categories.

Reference domain semantics do not transfer: Daily reports must have exactly Devotional reports / Ministry reports / Meetings reports. Ministry contains only Evangelism / Discipleship; teaching and prayer meetings belong in Meetings. No copied screen, invented role permissions, or claims of full-resolution flow research.

## Mobile drawer refinement — 9 October

Reviewed mobile screens from [Shopify](https://mobbin.com/screens/09e2a4bc-86c1-4d83-a3a6-823a67979c80), [ClickUp](https://mobbin.com/screens/3a56e297-6dac-400a-a4ff-be10543365d4) and [Spark Mail](https://mobbin.com/screens/1c58b6fc-91b4-42be-8073-79a6920733ca). Shopify distinguishes icon-bearing parents from indented text-only sublinks; ClickUp uses quiet child rows beneath expanded sections; Spark Mail separates folder/account hierarchy with indentation and selective icons. Selected parent icons + sentence case + text-only children. Single-open behaviour is the user's requirement, not inferred from static reference screenshots. Expansion uses 250ms smooth-out grid height, gentle opacity, and no transitions for reduced motion. Existing blue tokens remain unchanged.
