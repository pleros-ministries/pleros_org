## How to work here (user preferences)

**Workflow:**
- Push to `main` after each piece. The user doesn't want feature flags: build the behaviour on main and delete the old path in the same change.
- Never run a production migration without an explicit go-ahead. Write the SQL by hand (`drizzle-kit generate` hangs on its interactive prompt). Dry-run it inside `BEGIN … ROLLBACK`, and apply only when told.

**Shared database:**
- The local `DATABASE_URL` in `.env` is the shared production Neon database, so testing locally touches live data.
- Never create real conversations, handovers, invitations or assignments while testing, and revert any test toggles.
- Real member names must not appear in training videos or screenshots that leave the machine.

**Style:**
- Fonts: Sen headings over Be Vietnam Pro body text.
- Weight: nothing above 500 (no bold).
- Colour: never mint or light green; a sage icon chip is fine. No violet for Meetings. The Advanced SOGP violet card is accepted.
- Copy: sentence case, calm and mobile-first.
- Learner auth pages use a compact type scale (see `AGENTS.md`).

**Privacy:** never tell disciples, in learner-facing copy, that their discipler can read their quiz answers or written work.

**Other sessions:** they work on `main` in the same checkout at the same time. Stage only your own files and lines (`git update-index --cacheinfo` with a hashed blob works for partial files). Never sweep another session's dirty files into a commit.

**Framework:** this is Next.js 16.3 with Cache Components.
- Any page that reads the session needs `export const instant = false;`, or it throws the "Instant" error.
- Read `node_modules/next/dist/docs/` before changing framework behaviour.

## The big change: groups as oversight (19 October)

**The decision.** In a meeting on 19 October, the Pastor decided that groups replace the church org chart (Pastor → branch pastor → unit leader → worker). That chain stalled because nobody filled in the appointments.

**The model:**
- The leader of the group you're in is your overseer. You report there.
- The groups you lead appear under Oversight.

**User decisions:**
- **One overseer per person.** You're in one group and can lead many, up to 20.
- **Joining needs a one-tap accept.** Accepting while already in a group moves you, and the invitation page warns you first.
- **The org chart is retired** (units, unit leaders, workers), but branch pastor status and branch scope stay underneath.
- **An overseer sees the full daily report.** Saved contacts stay private to the member, their pastor and admins.
- **No conversion** of old unit appointments into invitations: people start afresh.
- **Groups are invite-only.** There's no Discover and no open joining. All member-made interest groups are closed.
